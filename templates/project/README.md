# Project template

1. Copy this folder into `src/content/projects/` and rename it to your project's slug, e.g. `src/content/projects/kaelte-als-zuhause/`. In the terminal: `cp -R templates/project src/content/projects/<slug>`. You can delete this README in the copy.
2. **Replace `cover.jpg`.** It is only a placeholder photo (884 × 1000 px). Your cover must be 3:2 and at least 2400 × 1600 px.
3. Replace everything in `[square brackets]` in `index.mdx` (German, all fields) and `en.mdx` (English text only).
4. Run `npm run validate`, then `npm run dev` and open your page. Every field is explained in [docs/CONTENT.md](../../docs/CONTENT.md).
