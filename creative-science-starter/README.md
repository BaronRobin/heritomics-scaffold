# Creative Science Hub: starter files

Starting point for the Creative Science hub (HS Kaiserslautern, Virtual Design).

| File | What it is |
|---|---|
| `CLAUDE_CODE_PROMPT.md` | The full prompt for Claude Code. Open this folder in VS Code, start Claude Code, and paste the prompt (or tell it to read the file). |
| `docs/DESIGN.md` | The design guide, based on the HS KL corporate design. |
| `src/styles/tokens.css` | Design tokens (colors, type, spacing). |
| `mockup/index.html` | Static mockup of the home page. |
| `mockup/experience.html` | Static mockup of an experience page. |
| `mockup/mockup.css`, `mockup/mockup.js` | Styles and small interactions for the mockup. |

## Viewing the mockup

Open `mockup/index.html` in a browser, or use the VS Code "Live Server" extension. The box in the bottom-right corner switches the font mode and, on the experience page, the project color. It is a mockup tool only and not part of the design.

The mockup loads Poppins and Anton from Google Fonts for convenience. The real site must self-host its fonts (see the privacy rules in the prompt).

## Before building

- Ask HS KL whether the Stratos/Matter license covers web use.
- Get the official logo files from the HS KL press office.
- See `docs/DESIGN.md`, section 13, for the other open questions.
